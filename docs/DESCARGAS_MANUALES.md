# Descargas manuales

Ficheros que no se han podido obtener desde el entorno de trabajo. Guárdalos en la carpeta `data-raw/` indicada y ejecuta el script de `scripts/etl/` en modo `local` (`MODO=local python3 -I scripts/etl/<script>.py`). Los scripts no vuelven a descargar si el fichero ya existe.
